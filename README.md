# 🎈 숫자 놀이터

유치원·초등학생이 놀이하듯 수학을 익히는 상호작용 웹 앱입니다.

## 놀이

| 놀이 | 🐣 쉬움 (유치원) | 🐥 중간 (초등 1~2학년) | 🦅 짱어려움 (초등 3~4학년) |
|---|---|---|---|
| 🔢 블록 맞추기 | 3×3 슬라이드 퍼즐 | 4×4 | 5×5 (게임 안에서 난이도 변경 가능, 셀카 퍼즐 모드 포함) |
| ⭕ 원 그리기 | 빨간 점을 중심으로 원 그리기 (단계 구분 없음) — [노원수학문화관 원 그리기 게임](https://bychoi-space.github.io/circle_game/index.html)을 앱 안에 띄워 보여 줍니다 | | |
| ➕ 셈하기 | 그림 덧셈·뺄셈 (10 이하) | 20 이하 덧셈·뺄셈 | 곱셈구구, 두 자리 덧셈·뺄셈 |
| ⚖️ 크기 비교 | 어느 쪽이 더 많을까? | >, =, < 기호 고르기 | 식끼리 크기 비교 |
| 🧩 규칙 찾기 | 모양 반복 규칙 | 뛰어 세기 수열 | 덧셈·뺄셈·곱셈 수열 |

- 한 판은 10문제, 뒤로 갈수록 조금씩 어려워집니다.
- 문제를 **소리로 읽어 줍니다** (글을 아직 못 읽는 어린이도 혼자 할 수 있게). 🔊 버튼으로 다시 듣기.
- 틀리면 한 번 더 기회를 주고, 두 번 틀리면 정답 칸을 반짝여 알려 줍니다. 처음에 맞힌 문제만 별을 받습니다.
- 효과음·읽어주기는 오른쪽 위 버튼으로 끌 수 있습니다.

## 개인정보

- 실명 대신 **별명(최대 10자)**과 캐릭터 이모지만 저장합니다.
- 점수는 Supabase `scores` 테이블에 저장되며, 행 수준 보안(RLS)으로 **읽기·추가만** 허용하고 수정·삭제는 막혀 있습니다.

## 구조

정적 사이트(빌드 과정 없음)라서 파일만 고쳐도 바로 반영됩니다.

```
index.html          화면 틀
style.css           디자인
app.js              문제 생성기와 화면 흐름 (MAKERS 객체에서 문제 난이도 조절)
config.js           Supabase 주소와 공개 키
supabase/schema.sql 점수 테이블과 보안 정책
```

`config.js`의 두 값을 비우면 점수는 각 기기에만 저장됩니다.
